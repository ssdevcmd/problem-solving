# 🧠 JavaScript Problem Solving

A collection of **JavaScript problem-solving exercises** created to improve my programming fundamentals, logical thinking, and problem-solving skills.

This repository contains problems ranging from **easy to intermediate**, covering JavaScript fundamentals, arrays, objects, functions, recursion, and more.

## 🎯 Goals

* Improve JavaScript fundamentals
* Develop logical thinking and problem-solving skills
* Practice writing clean and readable code
* Strengthen knowledge of JavaScript built-in methods
* Prepare for coding interviews and technical assessments
* Build consistency through regular practice

## 📝 Problem Structure

Each problem generally includes:

```text
Problem
Description
Example
Hint
Solution
```

Example:

```javascript
function factorial(n) {
    if (n === 0) {
        return 1;
    }

    return n * factorial(n - 1);
}
```

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project directory:

```bash
cd javascript-problem-solving
```

Run a JavaScript file using Node.js:

```bash
node filename.js
```

You can also run individual problems using the **Node.js** environment in VS Code.

## 💡 Learning Approach

For each problem, I try to:

1. Understand the problem
2. Identify the required logic
3. Think about edge cases
4. Write the solution
5. Test different inputs
6. Refactor the solution when possible
7. Review the concept behind the problem
